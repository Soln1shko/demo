# Журнал изменений

## 2026-10-22 — каркас и справочники

- Создан Python-проект с `uv`, `src`-layout и правилами работы только с синтетическими данными.
- Добавлены кредитный и некредитный каталоги с демонстрационными ID и метаданными источников.

## 2026-10-23 — inference API

- Добавлены локальные движки скоринга, NBA, прогноза кассового разрыва и предварительного выбора кредитов.
- Добавлены Qdrant/BM25-поиск, FastAPI, OpenAPI, Dockerfile и Docker Compose.
- Добавлены Underwriting, Decision Explainer, CRM Copilot, Document Parser и Offer Recovery.
- OpenRouter используется для текстовых задач и ранжирования уже допустимых кредитов; локальные расчёты остаются доступными без ключа.
- Общие JSON-разбор и строгая базовая модель вынесены в `src/app`; публичные функции и классы снабжены аннотациями и русскими Google-style docstring.

## 2026-10-23 — документация и проверка

- Перестроены README проекта и сервисов, подробный HTTP-контракт, карта архитектуры, границы MVP и карта артефактов.
- Описаны места, где результат синтетический, текст требует подтверждения сотрудником, а живой вызов OpenRouter не покрывается локальными тестами.
- Локальные проверки: Ruff format/check, mypy, pytest и `git diff --check`. Docker Compose собирает образ; `/health`, `/docs`, `/openapi.json` и пример `/v1/scoring` проверяются отдельным HTTP-сценарием.

Точный статус текущих проверок следует брать из последнего запуска команд, а не считать этот журнал автоматическим отчётом CI.

## 2026-10-23 — финансовый двойник и кредитный квест

- Добавлены локальный baseline-прогноз по месячной истории, денежные сценарии с аннуитетом и фиксированным seed, а также контрфактические действия с повторным вызовом действующего скоринга.
- Добавлены четыре HTTP-маршрута `/ml/*` и генератор трёх синтетических бизнесов.
- Эффект кредита на выручку задаётся явно; при уменьшении инвестиции он сокращается. Квест не меняет неподтверждённые свойства бизнеса и не обещает одобрения.
- Контракт, формулы, входные данные и ограничения перечислены в [README модуля](../../src/financial_intelligence/README.md).

## 2026-10-23 — уточнение границ Business Twin и Credit Quest

- Восстановлен `THIRD_PARTY_NOTICES.md`; в нём отмечено, что новый расчёт локальный.
- Из нового модуля удалена собственная оценка вероятности кассового разрыва. Её единственный API остаётся в `cash_cap`; Business Twin возвращает денежные траектории с кредитом и без него.
- По запросу пользователя удалён демонстрационный HTML-экран и его маршрут. Три синтетических профиля остаются доступны через `/ml/demo/{kind}`.
- Для прогноза сохранены расходы при нулевой выручке; сценарии кредита используют общую формулу движения денег. Квест отсекает планы, ухудшающие уже отрицательный денежный остаток.
- Итоги проверки на предметных кейсах: [отчёт](Проверка-Business-Twin-Credit-Quest-2026-10-23.md).

## 2026-10-23 — переход на Qwen через OpenRouter

- Модель по умолчанию сменена на `qwen/qwen3-32b`; локальный `.env` также переключён без изменения ключа.
- Для коротких генераций Qwen включён режим `/no_think`, потому что в обычном режиме токены могут уйти на рассуждение без итогового текста.
- Ассистент по знаниям теперь получает структурированный ответ и добавляет только проверенные ссылки на источники.
- На живом Docker API модель вернула `200` для `credit-advisor`, `assistant/answer`, `underwriting/summary`, `decision-explainer/refusal`, `crm-copilot/reply` и `documents/parse`. Последний маршрут прошёл реальный PaddleOCR на синтетическом PNG и извлёк выручку и расходы с цитатами OCR.
- Доступность провайдера и лимиты аккаунта могут меняться; этот прогон не является гарантией отсутствия будущих `429`.

## 2026-10-23 — поведенческие сценарии

- Проверены контрастные профили для скоринга, баннеров, кредитного советника, кассового разрыва, поиска и восстановления оффера через живой HTTP.
- Скорректирована применимость и ранжирование некредитных баннеров; улучшен русский поиск по кредиту продавцам маркетплейсов.
- Сценарии закреплены регрессионными тестами; результаты, границы LLM-проверки и оставшиеся ограничения записаны в [отчёте о поведении](Проверка-поведения-2026-10-23.md).
