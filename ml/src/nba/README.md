# Некредитные рекомендации для профиля

`NbaEngine` ранжирует сервисы малого и микробизнеса для баннеров профиля: РКО, эквайринг, СБП, кассу, бухгалтерию, ВЭД и другие **некредитные** продукты. Кредит, овердрафт, кредитная линия и рефинансирование не входят в его каталог.

## Контракт

`POST /v1/nba/recommendations` получает `legal_form`, возраст бизнеса, месячный оборот и число платежей, долю онлайн-продаж, количество сотрудников и признаки счёта, сайта, торговой точки, маркетплейсов, ВЭД, отчётности, электронных документов и регистрации. Необязательны `existing_product_ids[]` и `top_n` от 1 до 18 (по умолчанию 3). Уже подключённые продукты исключаются.

Ответ — JSON-массив `{product_id, score, reason}`. `score` — модельная релевантность от 0 до 1, не вероятность покупки или одобрения. `reason` выбирается из локальных текстов `config.py`. Если применимых продуктов меньше `top_n`, массив будет короче.

## Локальный расчёт

`model_weights.json` содержит веса по каждому некредитному `product_id`; `NbaEngine.from_json()` загружает их при старте, а `recommend()` строит признаки профиля, отсекает продукты без базового сценария, считает оценки и сортирует по убыванию. Например, зарплатный проект требует сотрудников, ВЭД — внешней торговли, услуги маркетплейсов — продаж на площадках. Веса ключевых признаков этих сценариев и офлайн-точки откалиброваны так, чтобы профильная услуга попадала в первые три баннера на контрольных контрастных профилях. При вызове нет сетевого I/O или LLM. Движок можно встроить в будущий интерфейс с однократной загрузкой `browser_payload()`; такого интерфейса здесь нет.

```python
from nba import BusinessProfile, NbaEngine

profile = BusinessProfile(
    legal_form="ip",
    business_age_months=12,
    monthly_turnover=1200000,
    monthly_payment_count=60,
    online_sales_share=0.7,
    has_business_account=True,
    has_website=True,
    has_offline_point=False,
    sells_on_marketplaces=True,
    employee_count=2,
    has_foreign_trade=False,
    needs_tax_reporting=True,
    uses_electronic_documents=False,
    wants_business_registration=False,
    existing_product_ids=("business_account",),
)
items = NbaEngine.from_json().recommend(profile, top_n=3)
```

## Данные и проверка

ID берутся из `data/Продукты-Альфа-Банка-вне-кредитов-МСБ.csv`. `tests/test_catalog_ids.py` проверяет согласованность каталога, конфигурации и весов. Логика профиля и HTTP-обёртка проверяются командами `uv run pytest -q tests/test_nba.py tests/test_api.py`. Каталог и оценки демонстрационные; фактическую доступность продукта нужно уточнять по актуальным условиям.
