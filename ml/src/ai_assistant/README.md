# Ассистент по базе знаний

Ассистент ищет сведения о продуктах и справочные материалы для ответа на вопрос предпринимателя. Он не получает заявку и не принимает кредитное решение.

## Индекс и поиск

При startup `build_knowledge()` формирует не менее 200 фрагментов из двух CSV-каталогов и справочных материалов с `source_url` и `effective_at`. `KnowledgeStore` идемпотентно загружает их в коллекцию Qdrant `business_knowledge_v2`; `Bm25Index` строится в памяти. Лексический индекс использует общую короткую основу длинных русских слов для сопоставления форм вроде «маркетплейса» и «маркетплейсов». Кредит продавцам маркетплейсов имеет отдельное поисковое название. Для запроса `MultilingualEncoder` создаёт вектор, Qdrant и BM25 возвращают кандидатов, а reciprocal-rank fusion объединяет ранги.

Модель эмбеддингов `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` загружается при первой подготовке среды; Docker-образ заранее кэширует её. По умолчанию без `QDRANT_URL` используется локальный Qdrant-путь `data/qdrant/`, в Compose — отдельный контейнер `qdrant`.

## HTTP-контракт

| Маршрут | Вход | Результат |
| --- | --- | --- |
| `POST /v1/assistant/search` | `query`, `limit` от 1 до 20 (по умолчанию 5) | Массив `{document, score}`; документ содержит `knowledge_id`, заголовок, текст, категорию, URL и дату среза |
| `POST /v1/assistant/answer` | Те же поля | `answer`, найденные `sources[]`, `model`, `usage` |

`search` полностью локален после startup. `answer` передаёт найденные фрагменты OpenRouter и требует JSON с текстом ответа и массивом `knowledge_ids`. JSON Schema ограничивает ID найденными фрагментами; сервер проверяет их и сам дописывает ссылки в квадратных скобках. Пустая или чужая ссылка даёт `502`. Это проверка происхождения факта, не доказательство его корректной интерпретации. Без ключа или при недоступности OpenRouter, включая лимит запросов провайдера, `answer` даёт `503`, а `search` продолжает работать.

```python
from ai_assistant import create_assistant

assistant = create_assistant()
try:
    sources = assistant.retrieve("Какие документы нужны для кредита?", limit=5)
finally:
    assistant.close()
```

## Ограничения и проверка

Справочные и продуктовые условия меняются. `effective_at` отмечает дату среза, но сам по себе не обновляет сведения. Промпт ограничивает ответ найденным контекстом; сотрудник или клиент должен сверять важные условия с актуальным источником. Проверка: `uv run pytest -q tests/test_ai_assistant.py tests/test_api.py`. HTTP-тест использует подменное хранилище и LLM; живой Qdrant проверяется запуском Compose.
