# Сторонние компоненты и источники

| Компонент | Использование | Где работает |
| --- | --- | --- |
| FastAPI, Pydantic, Uvicorn | HTTP API и контракты | Контейнер `app` |
| Qdrant, FastEmbed, BM25 | Хранение и гибридный поиск справочных знаний | Контейнер `qdrant` и процесс `app` |
| PaddleOCR / PaddlePaddle | Распознавание PDF и изображений, включая таблицы | Контейнер `app` |
| OpenRouter | Генерация резюме, объяснений и ответов; ранжирование допустимых кредитов | Внешний API при наличии ключа |
| Business Twin и Credit Quest | Локальные формулы денежного сценария и повторный вызов демонстрационного скоринга | Контейнер `app`, без внешнего API |
| Каталоги продуктов в `data/` | Демонстрационные правила и справочные фрагменты | Локальные CSV |

Сборка Docker-образа загружает ONNX-энкодер RAG; первый OCR-вызов может загрузить модели распознавания. Веса сохраняются в Docker volumes. Для автономной сборки нужно заранее подготовить зависимости и веса; запуск уже собранного образа не требует загрузки энкодера. В рабочем режиме документы клиента не отправляются в Qdrant: туда загружается только справочная база знаний. Для текстовых функций распознанный текст или данные заявки передаются в OpenRouter; в проекте предполагаются исключительно синтетические и обезличенные данные.

Подключений к ФНС, БКИ и банковским системам здесь нет. Их результаты в сценариях передаются как локальные демонстрационные данные. Лицензии и версии Python-зависимостей определяются их пакетами и `uv.lock`; этот файл описывает назначение компонентов, а не заменяет тексты лицензий.
