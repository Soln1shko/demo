# Память проекта

## 2026-10-22: старт

- Проект: АльфаХак, кейс «Умный кредитный кабинет предпринимателя».
- Роль владельца репозитория: ML Engineer. Реализация пойдёт сервис за сервисом.
- В проекте нет исходных данных. Для разработки, тестов и демо всегда используется качественная синтетика, с генератором, фиксированным seed и проверяемыми распределениями.
- На старте выделены пять направлений: подбор подходящего кредитного продукта, синтетическая скоринговая модель, персонализация баннеров/контента, прогноз кассового разрыва, чат с переводом на оператора.
- Обязательный фундамент из брифа: связный клиентский и внутренний банковский путь, сохранение состояния, Docker-запуск, lock-файл, README, синтетические тестовые данные, THIRD_PARTY_NOTICES, архитектурная схема, API/OpenAPI, коллекция запросов, диаграмма состояний, модель данных и тестовые сценарии.
- Скоринг и итоговое кредитное решение проектируются отдельными слоями. Упрощённая логика допустима, но все допущения явно документируются.

## Принцип ведения

Эта память хранит только устойчивые решения по проекту. После каждого завершённого сервиса добавлять сюда: назначение, контракт, источник синтетических данных, проверки, ограничения и команду воспроизведения.
